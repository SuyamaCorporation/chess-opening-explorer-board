# Chess Opening Explorer & Move Tree

## 概要
チェスボードをcanvasで描画し、8種類の代表的オープニングをドロップダウン選択して最初の5手をステップ再生する教育ツール。

## 機能
- canvasによるチェスボード描画（Unicode駒記号）
- 8種類のオープニング（ルイ・ロペス/シシリアン/クイーンズギャンビット等）
- 前・次の手ボタンでステップ再生
- 各手の解説表示
- 手の一覧表示（現在手ハイライト）
- リセット機能

## 使い方
ドロップダウンでオープニングを選択し、「▶」ボタンで次の手へ進みます。「◀」で前の手に戻れます。各手の意図と解説が右側に表示されます。
